# Сайт «Один поток»

Обычная статика: `index.html`, `styles.css`, `app.js`, папка `assets`.
Сервер не нужен — файл можно открыть двойным кликом.

## Что правят чаще всего
Всё в начале `app.js`:

* `CONTACTS` — телеграм, телефон, почта и **адрес кабинета** (кнопка «Войти в кабинет»).
* `PLATFORMS` — карточки площадок в бегущей строке на первом экране.
* `CHANNELS` — блок «Что делаем с каналами».
* `PRICES` — прайс агентства.

Тексты разделов — прямо в `index.html`, они подписаны комментариями.

## Посмотреть локально
```
npx --yes serve site -l 4321
```
Открыть http://localhost:4321

## Выложить на GitHub Pages
1. Скопировать содержимое папки `site` в репозиторий (например, `odin-potok`).
2. В настройках репозитория: Settings → Pages → Source: ветка `main`, папка `/root`.
3. Через пару минут сайт открывается по адресу `https://<логин>.github.io/<репозиторий>/`.

После переезда кабинета на постоянный адрес — поменять `CONTACTS.cabinet` в `app.js`.
